# ☕ Cafe Zero | سیستم هوشمند مدیریت سفارشات و مالی کافه

یک سیستم دسکتاپ سبک، سریع و ماژولار با معماری لایه‌ای (Service-Layer) برای مدیریت سفارشات، درآمد و نسیه مشتریان.

## ✨ قابلیت‌ها
- پردازش سفارشات لحظه‌ای با ثبت تخفیف و جزئیات مالی
- مدیریت مشتریان و تسویه حساب نسیه
- لایه مجزای دیتابیس با SQLite
