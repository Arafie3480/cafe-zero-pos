# کافه صفر | Cafe Zero

اپلیکیشن دسکتاپ پایتونی برای مدیریت سفارش‌های کافه، اطلاعات
مشتریان و ثبت داده‌های مالی در دیتابیس محلی SQLite.

> وضعیت پروژه: در حال توسعه و ارزیابی.
> این پروژه فعلاً به‌عنوان نمونه‌کار ارائه می‌شود و جایگزین
> نرم‌افزار حسابداری تأییدشده نیست.

## قابلیت‌های موجود در کد

- نگهداری اطلاعات محصولات و منوی کافه
- ثبت سفارش و اقلام آن
- مدیریت اطلاعات مشتریان
- ثبت بدهی و تسویه مشتریان
- محاسبه امتیاز مشتری در منطق سفارش
- گزارش مالی روزانه و تفکیک فروش بر اساس روش پرداخت

صحت عملکرد این قابلیت‌ها باید با سناریوهای آزمایشی بررسی شود.

## فناوری‌ها

- Python
- Tkinter برای رابط گرافیکی
- SQLite و ماژول sqlite3 برای ذخیره‌سازی داده‌ها
- dataclasses برای تعریف ساختار داده
- pathlib برای مدیریت مسیر فایل‌ها
